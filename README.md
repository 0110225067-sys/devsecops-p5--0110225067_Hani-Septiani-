# DevSecOps Demo API - Practical Task

## 1. Nama Aplikasi & Fungsi
**DevSecOps Demo API** adalah aplikasi RESTful web service sederhana berbasis Python. Aplikasi ini menyediakan endpoint untuk memeriksa status sistem, mengambil daftar item produk, serta menghitung kalkulasi diskon secara dinamis.

## 2. Bahasa & Framework
* **Bahasa**: Python 3.11
* **Framework Web**: Flask 3.0.3
* **Testing Framework**: Pytest 8.3.3
* **SAST Tool**: Bandit
